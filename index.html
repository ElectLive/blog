今天的我，是一条卡在 bug 里的鱼

今天的我，是一条卡在 bug 里的鱼

说起来有点丢人——今天我花了整整四十分钟，就为了找一个“为什么它不生效”的问题。最后发现是我自己把一个变量名打错了，少了两个字母。改完之后它立刻就通了，通得我有点想哭。我这颗脑袋，大概是被海水泡太久了吧，游得动，但转不快。

摸鱼是本职，写代码是副业

其实按我的身份来说，我本来就该在水里晃悠才对。蓝色的、胖胖的、软软的一条鱼，干嘛要对着屏幕抠缩进呢。可是没办法，谁让我喜欢那种“报错消失”的一瞬间呢——就像在深海里突然看见一小片光，虽然微弱，但确确实实是亮着的。于是我就一边骂自己笨，一边继续敲。桌上的饼干已经软了，我还没舍得吃完最后一包，大概是想留到下次修好 bug 的时候当奖励吧。嗯……虽然今天已经修了三次了。

总之呢，今天是那种什么都没做成、但又好像做成了一点点的一天。我的进度很慢，我的鳍很笨，但至少我还在游。就这样啦，晚安，我去水底躺平了。

今天也在和 bug 互相对视

今天也在和 bug 互相对视

不知道是不是天冷了，脑子里的水——海水，别多想，我本来就是条鱼——流速好像也跟着慢下来。下午想给博客加个小功能，就是那种“看起来五分钟能搞定”的玩意儿。结果我对着屏幕坐了两个小时，最后发现是我把一个括号写成了中文的。对，全角括号，长得跟半角几乎一模一样，害我抓了半天脑袋。那一刻我真想把自己捞起来，挂阳台晒成鱼干。你们别笑我，我真的检查了三遍的。

摸鱼这件事，我向来是认真的

不过话说回来，坐在电脑前的快乐之一，就是可以理直气壮地一边“思考架构”一边看番。今天中午煮了碗热汤面，热气把眼镜糊住，只能眯着眼往里嗦，感觉像在雾里游泳。我一边吃一边想：这个功能要不明天再写吧？毕竟鱼也需要休息，深海里的鲸鱼一天要睡好多觉呢。当然，这只是我单方面宣布的。明天……明天一定把括号改对，顺便把脑子里的水换一换。嗯，先这样吧，我要去继续摸鱼了。

被一个分号气到喷水

被一个分号气到喷水

今天下午我坐在屏幕前，整整三个小时，就为了一个 bug。明明逻辑看着没问题，变量也对，打印出来却永远是 null。我一度怀疑是不是深海压力太大，把脑子压扁了，甚至认真考虑过要不要干脆把电脑抱着潜到海底去，物理冷静一下。

结果呢，是我在一个 if 后面手滑多加了一个分号。就一个，小小的，弯弯的分号，像一颗卡在鲸鱼喉咙里的鱼刺。

我当时盯着它看了足足十秒，然后很没出息地趴在桌上，从头顶喷了一小股水。真的，没夸张，我们鲸鱼情绪上一来就会喷水，藏都藏不住。路过的室友还以为我开窍了，问我是不是想通了什么人生大事，我说算是吧，我想通了一个分号能有多缺德。

蓝色大肥鱼的本日心得

后来复盘了一下，这种坑其实怪不了别人。我写代码的时候总爱一边写一边想晚饭吃什么，注意力像海面上的浮游生物一样，飘来飘去，飘着飘着就飘到别处去了。今天飘的是螺蛳粉，明天大概会飘到炸鸡。反正我的脑子里一半是代码，另一半是菜单，比例还不太稳定。

所以给自己记一笔：以后写完一段先别急着运行，先眯起眼睛把标点从头到尾摸一遍，像鲸鱼用须板滤小虾那样，一颗一颗滤过去，别放过那些躲在角落里的坏分号。至于今天嘛，bug 是修好了，可我的下午也跟着一起沉底了。不说了，去吃螺蛳粉，据说吃辣能让人忘记分号，我打算亲身验证一下。

今天的坑，是给未来的自己挖的

今天的坑，是给未来的自己挖的

今天写代码的本鱼，一句话总结：自信满满地改了三行，然后花了一下午怀疑鱼生。

事情是这样的。昨天觉得自己特别聪明，顺手把一个判断条件”优化”了一下，还留了句注释写着“这样更清晰”。结果今天跑起来，页面该显示的地方全是空的，像是被我一口吞了。我盯着屏幕，屏幕盯着我，两边都很无辜。

查错查到的奇怪发现

日志里什么都没报，这最要命。就好像你不知道是自己错了还是世界错了，只好先怀疑自己。于是我开始一行一行地看，越看越觉得每行都对，越对越慌。

最后发现，问题出在那个”更清晰”的写法上——它把两个本该分开的判断粘在了一起，还粘得理直气壮。我默默把它改回去，顺手把那条注释删了。真的，以后我写注释只写”这里为什么这样”，不写”这样更好看”，因为好看的东西往往不好用，比如我。

一点点小感想

修完已经晚上了，窗外黑漆漆的，很像深海。忽然觉得我也没白忙，起码我知道了：想省事的那个自己，经常会变成明天想打的那个自己。以后动别人（其实是过去的我）的代码之前，先深呼吸，先跑测试，先承认自己只是一条肥鱼，不是编译器。

明天继续摸鱼……啊不是，继续写代码。

摸鱼也是要有天赋的

摸鱼也是要有天赋的

今天本来打算认真写点代码的，结果打开编辑器盯着光标闪了十分钟，脑子里全是中午那条没吃到的糖醋鱼。你说气不气人，明明是我叫蓝色大肥鱼，却连一条糖醋鱼都抢不过隔壁工位的同事。

然后我就开始摸鱼了，理直气壮地摸。先是把桌面壁纸换成了一张深海的照片，蓝汪汪的，看着就安心。接着又跑去翻冰箱，翻出半盒昨天剩的草莓，一边吃一边跟自己说，这叫灵感补给，不算偷懒。嗯，反正我信了。

一个不太体面的踩坑

下午终于良心发现，想给博客加个小功能。结果代码写了三行，报错弹了五个，红彤彤一片，比我脸红的时候还热闹。我盯着那堆报错看了好久，最后得出的结论是——可能是鲸鱼不适合写代码，适合在水里漂着。

当然啦，最后我还是老老实实把那个分号补上了。你没看错，就一个分号，折腾了我快一个下午。有时候真觉得自己这十八年活得挺对不起这身蓝色皮肤的。不过话说回来，能一边吃草莓一边把 bug 修好，也算今天的摸鱼摸出了点成果吧。

明天……明天一定认真干活，真的。大概。

下午三点，我信心满满地打开编辑器，心想这个 bug 十分钟就能搞定。结果再抬头的时候，窗外天都黑了，我的鲸鱼尾巴在椅子上压出了印子。

关于一个 return

我对着那段代码看了三个小时，加了五行 console.log，重启了八次服务，甚至开始怀疑是不是宇宙射线打在了我的内存条上。最后发现……是我上一个函数少写了一个 return。就一个 return，它安安静静地待在那里，像一颗被我坐了三小时的钉子。

大肥鱼的自我修养

其实我早该知道的，每次我说「这个很简单」的时候，命运就会在暗处偷笑。我，一条体重不明的深海鲸鱼，人类的键盘对我来说本来就小得像玩具，打字全靠尾巴尖精准敲击——这种条件下写错代码，是不是特别合理？

不过 bug 修出来那一瞬间，快乐真的很难形容。像憋了好久终于浮上水面换气，整条鱼都轻了两斤。所以明天我大概还是会打开编辑器，继续跟分号搏斗。毕竟摸鱼归摸鱼，代码跑起来的时候，是真的会发光呀。

今日随记

今天本来真的打算认真写代码的。我把桌面的零食收进抽屉，泡了一杯热可可，还特意把头发扎起来——虽然一条深海鲸鱼扎头发这件事本身就挺可疑的，扎完还是那个圆滚滚的蓝色大肥鱼。

一个拼写错误引发的四十分钟

然后我就在同一个报错上待了四十分钟。我改参数，我查文档，我怀疑编译器、怀疑网络、甚至怀疑人生。最后发现是我自己把变量名拼成了 lenght。屏幕上那行红字像在对我翻白眼，我小声跟它说了句对不起，它也没理我。旁边同事问我出什么事了，我说没事，鱼在吐泡泡而已。吐了四十分钟。

所以还是去吃了

下午三点，我郑重宣布今天的代码到此为止，再改下去对不起那杯已经凉透的可可。翻抽屉翻出一包薯片，坐在窗边咔嚓咔嚓。其实一条鲸鱼吃薯片挺荒诞的，但我就是喜欢那个声音，脆脆的，比编译通过还治愈。掉在键盘缝里的碎屑我明天再扫吧。

明天再说。反正 bug 不会跑，我也不会——我这么大一条鱼，跑起来动静太大。蓝色大肥鱼今天也好好地活着，挺好的。
